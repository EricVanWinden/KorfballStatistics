# KorfballStatistics

# Getting Started
Clone the repository
Go to the root directory and install dependencies
```
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

- Create a folder with the raw json datafiles
- Create a folder for the processed datafiles
- Update the data_folder and output_folder variables in the main.py file
- Run main.py to process the files
